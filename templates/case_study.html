01 — The Problem

Mid-sized brands are flying blind online.

Two years working in digital marketing showed me the same gap everywhere: businesses had no picture of their Google presence, and the tools that could show them cost more than their entire marketing budget.

1
No visibility into SEO performance

Most SMBs don't know why Google ranks them where it does — or what it would take to move up a single position.

2
Enterprise tools cost more than their marketing budget

Ahrefs, Semrush, and Moz run hundreds per month — built for agencies, not solo founders.

3
The gap I decided to close

Same Google data. Same AI analysis. Under 90 seconds. Free.

02 — The Solution

An in-house mini marketing agency, for companies that can't afford one.

Paste any URL and get a plain-language breakdown of how that brand appears online in under 90 seconds — real SEO scoring, tone analysis, keyword gaps, and prioritized fixes. No jargon. No retainer. No waiting.

03 — How It's Built

Full-stack, from terminal to live URL.

Built end-to-end as a solo project — from writing Python in VS Code, pushing commits through Git, to watching the first successful deploy on Render. My MIS coursework in database systems, REST APIs, and cloud platforms connected directly to real production decisions.

Python / Flask Anthropic API PostgreSQL Google PageSpeed API Render Gunicorn BeautifulSoup Git / GitHub
04 — What I Learned

Shipping taught me things no class could.

Building for production — not for a grade — meant every mistake had a real consequence. The site either worked or it didn't.

1
AI APIs in production are unpredictable

I cycled through multiple model versions as APIs changed mid-build. Each change broke the site. Working through that taught me more about how LLMs are deployed than any tutorial could.

2
The gap between local and production

The app ran perfectly on my MacBook. On Render, SSL handshakes timed out and environment variables had to be managed carefully. I learned to read server logs and diagnose problems I'd never seen before.

3
Git as a real workflow tool

Pushing commits through the terminal to trigger live deploys made version control feel like a real professional skill rather than an academic exercise.

05 — Where It Stands

Live, real, and still growing.

BrandScan AI is deployed and running at brandscan-ai.onrender.com. Any business can paste their URL and get a full brand audit in under 90 seconds — powered by real Google data and AI analysis.

This isn't a mock-up. It's a product I built from a gap I saw in my own professional experience, using skills from two years in digital marketing and my MIS coursework.
